## Questionário

### Qual é a diferença entre Working Directory, Staging Area e Repository?

O Working Directory é onde ficam os arquivos que estamos trabalhando.

A Staging Area é onde ficam os arquivos preparados para o próximo commit.

O Repository é onde ficam armazenados os commits e o histórico do projeto.

### Qual é a diferença entre git commit e git push?

O git commit salva as alterações no repositório local.

O git push envia os commits locais para o repositório remoto no GitHub.

### É possível realizar vários commits antes de executar um git push?

Sim. Podemos realizar vários commits localmente antes de executar o git push.

### Por que é interessante realizar commits pequenos e descritivos?

Porque facilita entender o histórico do projeto e identificar o que foi alterado em cada etapa.

### O que acontece com os commits locais quando ainda não executamos o git push?

Eles continuam salvos no repositório local, mas ainda não foram enviados para o GitHub.

### Como verificar, pelo GitHub, se os commits foram enviados corretamente?

Podemos acessar o repositório no GitHub e verificar o histórico de commits.
